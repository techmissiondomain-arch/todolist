# assets

Put your background image here as **`background.jpg`** (this exact name).

The app's CSS (`styles.css`, in the `body` rule) loads `assets/background.jpg`
as the page backdrop. The sidebar and main content sit on translucent
"frosted glass" panels so your tasks stay readable over the photo.

To use a different file name or type (e.g. `.png`), update the
`background-image: url("assets/background.jpg")` line in `styles.css`.
